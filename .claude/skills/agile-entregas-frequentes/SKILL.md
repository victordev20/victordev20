# Agile — Entregas Frequentes e Foco no Valor (André Faria Gomes)

Livro-fonte: `LivrosDev/Agile - Desenvolvimento de Software com Entregas Frequentes e Foco no Valor de Negócio - Autor (Casa do Código).pdf`

## Estrutura
1. **Introdução a métodos ágeis** — Manifesto e valores; Scrum (mais valor), XP (excelência técnica), Kanban (fluxo contínuo); não há "melhor método", combine.
2. **Fluência ágil** — maturidade da equipe evolui por estágios; Cynefin (ordem, caos, complexidade) para escolher abordagem.
3. **Foco em valor de negócio** — visão do projeto, planejamento iterativo, planejamento de iteração, reunião diária, **limite de WIP**, **histórias de usuário** (INVEST, critérios de aceitação), **mapeamento de histórias**, **personas**, estimativas, **planejamento de releases**, **roadmap**, manter opções abertas (decidir no último momento responsável).
4. **Entregando valor** — testes ágeis, TDD, integração contínua, refatoração, programação em par, design incremental, entrega contínua.
5. **Melhoria contínua** — retrospectivas, métricas, kaizen.

## "E agora, o que eu faço amanhã?"
Cada capítulo termina com ações. Use este modelo de checklist:
- [ ] A visão do produto está escrita e visível?
- [ ] O backlog está ordenado por valor e as histórias têm critérios de aceitação?
- [ ] Existe limite de WIP?
- [ ] Há um mapa de histórias para o próximo release?
- [ ] Testes automatizados e CI rodam a cada commit?
- [ ] A última retrospectiva gerou ações concretas com dono?

## Formato de história
`Como <persona>, quero <ação> para <benefício>` + critérios de aceitação "Dado / Quando / Então".
