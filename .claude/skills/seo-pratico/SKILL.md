# SEO Prático — Casa do Código

Livro-fonte: `LivrosDev/SEO Prático - Seu Site na Primeira Página das Buscas - Autor (Casa do Código).pdf`

## Como funciona a busca
- **Spiders** rastreiam, buscadores **indexam** e **ranqueiam**; PageRank (links como votos); atualizações (Panda: qualidade de conteúdo; Penguin: links artificiais; Hummingbird: intenção/semântica).
- Aparecer não basta: o resultado precisa gerar **clique** e **conversão**.

## Projeto de SEO
1. **Keyword research:** entenda a cabeça do usuário (intenção informacional, navegacional, transacional), termos que você quer ranquear, **cauda longa**, volume × concorrência, relacione palavras relevantes; impacto do nome do negócio e do domínio.
2. **Arquitetura:** hierarquia clara, URLs amigáveis, links internos, breadcrumbs.
3. **On-page:** `<title>` único (~60 caracteres, palavra-chave no início), meta description persuasiva, um `h1`, headings hierárquicos, conteúdo original e completo, `alt` em imagens, dados estruturados (schema.org).
4. **Técnico:** `robots.txt`, **sitemap.xml**, **canonical**, 301 para mudanças de URL, evitar conteúdo duplicado, HTTPS, **velocidade**, **mobile-friendly**, indexação via Search Console.
5. **Off-page:** link building legítimo (conteúdo que merece links, parcerias, PR), evitar esquemas de links.
6. **Local:** Google Meu Negócio, NAP consistente, avaliações.
7. **Medição:** Search Console (impressões, CTR, posição), Analytics (tráfego orgânico, conversões).

## Checklist por página
- [ ] Palavra-chave principal definida
- [ ] Title e meta description únicos
- [ ] H1 único e conteúdo responde à intenção
- [ ] URL curta e descritiva
- [ ] Imagens otimizadas com alt
- [ ] Canonical e indexável
- [ ] Carrega rápido em mobile
