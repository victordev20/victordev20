# More Agile Testing — Lisa Crispin & Janet Gregory

Livro-fonte: `LivrosDev/More Agile Testing - Learning Journeys for the Whole Team - Autor (Lisa Crispin).pdf`

## Temas
1. **Evolução e cultura:** qualidade é do time inteiro; cultura de aprendizado, transparência e loops de feedback; gestão de testers.
2. **Aprender para testar melhor:** competências vs papéis, **T-shaped skills**, especialistas generalistas, contratar e integrar testers; **habilidades de pensamento** (facilitação, resolução de problemas, dar e receber feedback, aprender o domínio, colaboração com cliente).
3. **Planejamento:** níveis de precisão (release → feature → história → tarefa), visualizar o que testar (mind maps), riscos.
4. **Testar valor de negócio:** perguntar "estamos construindo a coisa certa?"; **guiar o desenvolvimento com exemplos** (ATDD, BDD, Specification by Example).
5. **Testes exploratórios:** charters, personas, tours, sessões com timebox, heurísticas; testes de atributos de qualidade (segurança, performance, usabilidade, acessibilidade).
6. **Automação:** pirâmide de automação, design de testes mantíveis, quem escreve (time todo), ferramentas.
7. **Testes no contexto DevOps:** CI/CD, ambientes, testes em produção, monitoramento.
8. **Contextos:** times distribuídos, grandes organizações, sistemas legados, mobile/embarcado, ambientes regulados.

## Quadrantes de testes ágeis
| | Apoiam o time | Criticam o produto |
|---|---|---|
| **Voltados ao negócio** | Q2: exemplos, testes funcionais, protótipos | Q3: exploratórios, usabilidade, UAT |
| **Voltados à tecnologia** | Q1: unitários, componentes | Q4: performance, segurança, "ilities" |

## Checklist de estratégia
- [ ] Exemplos/critérios definidos antes de codar
- [ ] Os 4 quadrantes considerados para cada feature relevante
- [ ] Automação segue a pirâmide
- [ ] Sessões exploratórias com charter registradas
