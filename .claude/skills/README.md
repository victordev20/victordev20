# Skills da BibliotecaDev

Uma skill do Claude Code para cada livro de [KAYOKG/BibliotecaDev/LivrosDev](https://github.com/KAYOKG/BibliotecaDev/tree/main/LivrosDev).
Cada pasta tem um `SKILL.md` com as ideias centrais do livro, um passo a passo de como aplicar e checklists.
O Claude Code carrega essas skills automaticamente a partir de `.claude/skills/` quando o assunto da tarefa bate com a descrição da skill, ou você pode chamar uma pelo nome (ex.: `/codigo-limpo`).

> Os 109 PDFs viraram 107 skills: *Range* e *Por que os Generalistas Vencem* são a mesma obra (EN/PT), assim como *The Passionate Programmer* e *O Programador Apaixonado*; cada par compartilha uma skill.
